# Preview images

Design mocks of the ShipBrief Rovo agent, rendered from static HTML before deployment (the app cannot be screenshotted for real until it is installed on a site with the user's Atlassian API token).

- `chat-release-brief.png` / `.html` — release brief conversation (verdict, ranked blockers, stale work, next actions)
- `chat-issue-brief.png` / `.html` — single work item brief (people, blockers, Teamwork Graph goals)

All project keys, names, and numbers in these images are sample data. Replace both PNGs with real screenshots from the installed app before submitting to Devpost (see `../SUBMISSION.md`, runbook step 8).
